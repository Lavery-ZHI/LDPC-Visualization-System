# 🖱️ 可拖拽面板使用指南

## 🎉 新功能概述

现在您的LDPC应用支持两项重要的用户界面改进：

1. **关闭矩阵滚轮缩放** - 避免意外缩放干扰
2. **可拖拽调整面板大小** - 自定义界面布局

## 🔧 功能详解

### 1. 矩阵滚轮缩放已关闭

**改进前**：在矩阵上滚动鼠标滚轮会意外缩放矩阵
**改进后**：
- ✅ 滚轮缩放已禁用
- ✅ 保留拖拽平移功能
- ✅ 仍可使用缩放按钮 (+、-、⌖)

### 2. 可拖拽调整面板大小

#### 🖥️ 大屏幕模式 (≥1200px)
**三个可调整区域**：
- 📋 **左侧控制面板** - LDPC参数设置
- 🎨 **中间图形区域** - 图形编辑器
- 📊 **右侧结果面板** - 矩阵显示和分析

**操作方式**：
1. **鼠标悬停**：在区域之间的边界上，鼠标会变成 ↔️ 调整大小光标
2. **拖拽调整**：按住左键拖动分割线调整区域大小
3. **最小宽度**：每个面板都有250px的最小宽度限制

#### 📱 小屏幕模式 (<1200px)
**四个Tab页面**：
- 🔧 **Controls** - 控制面板
- 🎨 **Graph** - 图形编辑
- 📊 **Results** - 结果显示
- 📱 **Split** - 分割视图 (新增)

**分割视图特点**：
- 上半部分：图形编辑器
- 下半部分：结果显示
- 中间有可拖拽的 ↕️ 分割线

## 🎮 操作指南

### 大屏幕模式操作
1. **调整左侧面板**：
   - 将鼠标移到左侧面板右边界
   - 出现 ↔️ 光标时按住拖拽
   - 向右拖 = 扩大控制面板
   - 向左拖 = 缩小控制面板

2. **调整右侧面板**：
   - 将鼠标移到右侧面板左边界
   - 出现 ↔️ 光标时按住拖拽
   - 向左拖 = 扩大结果面板
   - 向右拖 = 缩小结果面板

3. **中间区域自动调整**：
   - 图形区域会自动填充剩余空间
   - 保证最佳的编辑体验

### 小屏幕模式操作
1. **使用Tab切换**：点击不同Tab查看不同功能
2. **分割视图**：
   - 点击"Split" Tab进入分割模式
   - 拖拽中间的分割线调整上下区域大小
   - 上方编辑图形，下方查看结果

## 📐 技术参数

### 大屏幕分割面板
```
初始宽度分配：
- 左侧面板：屏幕宽度的25% (300-450px)
- 右侧面板：屏幕宽度的30% (350-500px)
- 中间面板：剩余空间

约束条件：
- 最小面板宽度：250px
- 分割器宽度：8px
- 响应式调整：支持
```

### 小屏幕分割面板
```
初始高度分配：
- 上方面板：400px
- 下方面板：剩余高度

约束条件：
- 最小面板高度：200px
- 分割器高度：8px
- 垂直调整：支持
```

## 💡 使用技巧

### 1. 最佳布局建议
- **编码工作**：扩大左侧控制面板，方便参数调整
- **矩阵分析**：扩大右侧结果面板，详细查看矩阵
- **图形设计**：缩小两侧面板，专注图形编辑

### 2. 不同场景布局
- **参数调试**：左侧宽，右侧中等，中间正常
- **结果分析**：左侧窄，右侧宽，中间正常
- **图形设计**：左侧窄，右侧窄，中间宽

### 3. 小屏幕优化
- 使用Split视图同时查看图形和结果
- 根据需要调整上下区域比例
- 善用Tab切换快速访问功能

## 🛠️ 自定义配置

如需修改默认参数，可在以下位置调整：

### 面板初始大小
```dart
// 文件：main_screen.dart
final initialLeftWidth = (screenWidth * 0.25).clamp(300.0, 450.0);  // 左侧25%
final initialRightWidth = (screenWidth * 0.3).clamp(350.0, 500.0); // 右侧30%
```

### 最小面板大小
```dart
// 文件：resizable_panels.dart
minPanelWidth: 250.0,     // 水平最小宽度
minPanelHeight: 200.0,    // 垂直最小高度
```
