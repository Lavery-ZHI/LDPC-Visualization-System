# 🔍 矩阵查看器优化改进

## 概述
针对用户反馈的矩阵显示区域过小的问题，我们对矩阵查看器进行了全面优化，提供更大、更清晰的矩阵显示效果。

## 🎯 主要改进

### 1. 显示区域扩大
- **矩阵容器高度**：从 `120-200px` 增加到 `180-320px`
- **可用空间比例**：从 `25%` 增加到 `35%`
- **图表区域调整**：从 `40%` 减少到 `30%`，为矩阵腾出更多空间

### 2. Cell 尺寸优化
- **默认 cell 大小**：从 `20px` 增加到 `24px`
- **动态 cell 范围**：从 `12-20px` 增加到 `18-28px`
- **计算基数调整**：从 `宽度/25` 改为 `宽度/20`

### 3. 显示质量提升
- **字体大小**：索引字体从 `6-10px` 增加到 `8-12px`
- **内容文字**：从 `6-8px` 增加到 `8-12px`
- **边框加粗**：从 `0.3px` 增加到 `0.8px`，颜色从 `grey[700]` 改为 `grey[600]`

### 4. 交互体验优化
- **缩放比例**：从 `1.2倍` 增加到 `1.3倍`
- **最大缩放**：从 `5.0倍` 增加到 `8.0倍`
- **内边距**：从 `4px` 增加到 `12px`

### 5. 颜色对比度优化
- **蓝色cell**：从 `blue[600]` 改为 `blue[500]`
- **灰色cell**：从 `grey[850]` 改为 `grey[800]`
- **橙色cell**：从 `orange[600]` 改为 `orange[500]`

## 📊 对比效果

### 改进前
```
- 矩阵高度: 120-200px
- Cell大小: 12-20px
- 字体大小: 6-10px
- 边框: 0.3px
- 最大缩放: 5.0x
```

### 改进后
```
- 矩阵高度: 180-320px (+60%)
- Cell大小: 18-28px (+40%)
- 字体大小: 8-12px (+20%)
- 边框: 0.8px (+167%)
- 最大缩放: 8.0x (+60%)
```

## 🎮 使用指南

### 缩放操作
1. **鼠标滚轮**：在矩阵上滚动进行缩放
2. **缩放按钮**：使用 `+` `-` 按钮精确缩放
3. **重置按钮**：使用 `⌖` 按钮重置到默认大小
4. **拖拽查看**：按住鼠标左键拖动查看矩阵不同区域

### 显示模式
- **完整模式**：cell ≥ 16px 时显示行列索引
- **图标模式**：cell ≥ 14px 时显示图标
- **紧凑模式**：小cell时仅显示颜色块

### 信息查看
- **右上角显示**：缩放比例实时更新
- **统计信息**：行数、列数、密度、缩放比例
- **颜色编码**：
  - 🔵 蓝色：值为 1
  - ⚪ 灰色：值为 0
  - 🟠 橙色：其他值

## 🔧 技术细节

### 响应式计算
```dart
// 动态高度计算
final availableHeight = constraints.maxHeight * 0.35;
final matrixHeight = availableHeight.clamp(180.0, 320.0);

// 动态cell大小
final cellSize = (constraints.maxWidth / 20).clamp(18.0, 28.0);
```

### 缩放算法
```dart
// 放大
final newScale = (_scale * 1.3).clamp(0.1, 8.0);

// 缩小
final newScale = (_scale / 1.3).clamp(0.1, 8.0);
```

## 🎨 自定义选项

### 调整默认cell大小
在 `matrix_viewer.dart` 中修改：
```dart
const MatrixViewer({
  this.cellSize = 24.0,  // 修改此值
});
```

### 调整显示阈值
```dart
final showIndices = widget.cellSize > 16;  // 索引显示阈值
final showIcons = widget.cellSize > 14;    // 图标显示阈值
```

### 调整颜色方案
```dart
Color _getCellColor(int value) {
  switch (value) {
    case 1: return Colors.blue[500]!;    // 修改颜色
    case 0: return Colors.grey[800]!;
    default: return Colors.orange[500]!;
  }
}
```
