## 🎯 启动应用

### 方法1：一键启动（推荐）

这将自动：

- 启动后端服务器
- 启动前端应用

### 方法2：分别启动
```bash

cd backend
python main.py

# 终端2: 启动前端
cd my_ldpc_app
flutter run -d windows
```

## 🎨 新功能亮点

### ✨ 解码功能完整集成
- **3种解码模式**：LLR、AWGN、BSC
- **2种解码算法**：Min-Sum、Sum-Product
- **参数自定义**：最大迭代次数、缩放因子等
- **实时反馈**：解码状态、统计信息显示

### 🔄 智能响应式布局
- **自动适配**：根据屏幕大小自动选择最佳布局
- **流畅切换**：调整窗口大小时平滑过渡
- **内容保护**：滚动支持确保内容不被遮挡

### 🎯 优化的用户体验
- **紧凑设计**：充分利用屏幕空间
- **清晰层次**：信息组织更加合理
- **操作便捷**：按钮和控件位置优化

## 📋 使用流程

### 1. 创建LDPC图
```
大屏幕: 左侧面板 → 图形编辑区域
中屏幕: 左侧面板 → 右上图形区域
小屏幕: Graph Tab → 全屏图形编辑
```

### 2. 生成LDPC码
```
• 点击 "Generate LDPC Code"
• 查看H矩阵和G矩阵
• 确认码率和参数
```

### 3. 配置解码参数
```
解码模式选择:
├─ LLR: 直接输入对数似然比
├─ AWGN: 接收信号 + 噪声方差
└─ BSC: 接收比特 + 错误概率

算法选择:
├─ Min-Sum: 快速近似算法
└─ Sum-Product: 精确标准算法
```

### 4. 执行解码
```
• 点击 "Decode Data"
• 查看解码比特
• 分析统计信息
```

## 🔧 响应式特性详解

### 控制面板自适应
- **滚动支持**：内容过多时自动显示滚动条
- **紧凑模式**：输入框和按钮尺寸优化
- **动态字段**：根据解码模式显示相应输入

### 结果显示优化
- **矩阵可视化**：根据屏幕大小调整单元格尺寸
- **信息层次**：重要信息突出显示
- **性能图表**：小屏幕时自动隐藏

### 图形编辑区域
- **自适应大小**：根据可用空间调整
- **操作一致性**：所有布局下操作方式相同
- **清晰边界**：视觉分割明确

## 📊 性能提升

### 渲染优化
- **条件渲染**：根据屏幕大小选择性渲染组件
- **布局缓存**：避免重复计算
- **滚动性能**：优化滚动区域

### 内存使用
- **懒加载**：按需加载组件
- **资源管理**：及时释放不需要的资源
- **状态优化**：减少不必要的状态更新

## 🎯 最佳实践

### 推荐屏幕尺寸
- **最佳体验**：1920x1080或更高
- **良好体验**：1366x768或更高
- **基本体验**：1024x768或更高

### 使用建议
1. **大屏幕**：使用三栏布局，充分利用空间
2. **中屏幕**：使用两栏布局，平衡功能和显示
3. **小屏幕**：使用Tab布局，分类管理功能

### 性能建议
- 定期清理画布以释放内存
- 避免创建过大的LDPC图
- 合理设置解码参数以平衡性能和精度

## 🐛 问题排查

### 常见问题
1. **内容重叠**：已通过滚动支持解决
2. **布局错乱**：刷新页面或调整窗口大小
3. **按钮无响应**：检查是否已生成LDPC码

### 性能问题
1. **滚动卡顿**：减少同时显示的内容
2. **切换慢**：清理浏览器缓存
3. **内存占用高**：重启应用
