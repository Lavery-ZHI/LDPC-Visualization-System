# LDPC Designer 功能演示脚本

## 演示流程

### 1. 启动应用 (30秒)
1. 打开终端，启动后端服务器
   ```bash
   cd backend
   python main.py
   ```
2. 打开新终端，启动前端应用
   ```bash
   flutter run -d chrome
   ```
3. 等待浏览器打开，显示应用界面

### 2. 图形构建演示 (60秒)
1. **添加节点**:
   - 点击 "Add Variable" 按钮3次，添加3个变量节点
   - 点击 "Add Check" 按钮2次，添加2个校验节点
   - 展示节点在画布上的显示效果

2. **创建连线**:
   - 点击第一个变量节点 V1
   - 点击第一个校验节点 C1，创建连线
   - 重复操作，创建以下连接：
     - V1 → C1, C2
     - V2 → C1, C2  
     - V3 → C2
   - 展示连线的可视化效果

3. **节点属性查看**:
   - 长按某个节点，显示属性对话框
   - 展示节点ID、类型、度数信息

### 3. 模板加载演示 (30秒)
1. 点击 "Template" 按钮
2. 选择 "(3,6) Regular LDPC" 模板
3. 观察自动生成的规则图结构
4. 查看右上角的图统计信息

### 4. 编码生成演示 (45秒)
1. 点击 "Generate H & G Matrices" 按钮
2. 等待处理完成
3. 在右侧面板查看：
   - 状态更新为 "LDPC code generated successfully"
   - H 矩阵的可视化显示
   - 码率等参数信息

### 5. 仿真运行演示 (60秒)
1. **设置参数**:
   - SNR 设置为 4.0 dB
   - Frames 设置为 1000

2. **运行仿真**:
   - 点击 "Run Simulation" 按钮
   - 观察状态变为 "Running..."
   - 等待仿真完成

3. **查看结果**:
   - 查看 BER 值
   - 观察 BER 性能曲线
   - 展示 H 矩阵的详细可视化

### 6. 优化功能演示 (90秒)
1. **进入优化页面**:
   - 点击应用栏中的优化按钮
   - 进入遗传算法优化界面

2. **设置优化参数**:
   - Generations: 50
   - Population Size: 20
   - Mutation Rate: 0.1

3. **运行优化**:
   - 点击 "Start Optimization"
   - 观察实时收敛曲线
   - 展示最优结果统计

### 7. 高级功能演示 (45秒)
1. **矩阵查看器**:
   - 展示矩阵的缩放、平移功能
   - 查看矩阵密度统计
   - 演示矩阵的详细视图

2. **随机图生成**:
   - 点击 "Random" 按钮
   - 展示自动生成的随机图结构
   - 对比不同图结构的特性

### 8. 响应式设计演示 (30秒)
1. 调整浏览器窗口大小
2. 展示界面的自适应布局
3. 演示移动端友好的界面设计
